# 💰 Personal Expense Tracker with Data Visualization

A Python-based Personal Expense Tracker project that helps users analyze, visualize, and understand their spending habits using financial analytics and professional data visualization.

---

# 📌 Project Overview

Managing personal finances manually is difficult and often leads to overspending and poor budgeting.

This project solves that problem by:
- Tracking expenses
- Categorizing spending
- Analyzing monthly trends
- Generating visual insights
- Creating financial reports automatically

The project demonstrates:
- Python programming
- Data analysis
- Financial analytics
- Data visualization
- Automation skills

---

# 🚀 Features

✅ Synthetic expense dataset generation  
✅ CSV-based data storage  
✅ Expense categorization  
✅ Monthly expense analysis  
✅ Payment method analysis  
✅ Average daily spending calculation  
✅ Highest spending category detection
